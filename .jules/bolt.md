## 2025-09-09 - Memoize match engine `calcTeamStrength`
**Learning:** `calcTeamStrength(side)` is called multiple times per simulated minute across offside, passing, shooting, tactics, and possession phases. On every call, it performs array filtering on squad players, manager ratings, playstyle modifiers, and formation shape calculations. Caching team strength on `side._strengthCache` keyed by on-pitch player IDs (`ids.join(',')`) and formation shape (`side.squad.formation`) allows $O(1)$ lookups that automatically invalidate when substitutions, red cards, or tactical formation changes occur.
**Action:** When working on match simulation hot paths, memoize squad-level computations on the match side state using lineup ID keys rather than re-scanning squad arrays every tick.
