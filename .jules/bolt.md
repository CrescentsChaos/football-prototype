## 2025-05-18 - Caching Player Attribute Skills in Match Engine Hot Path
**Learning:** `hasSkill(p, skillName)` is called hundreds to thousands of times during match and season simulations across shooting, passing, fatigue, defending, and decision-making logic. The original implementation executed regex string normalizations on both the skill argument and every skill in `p.expandedAttrs.skills` array via `.some()`, causing heavy string allocations and O(N) array scans per check. Because player objects and attributes can be serialized or manipulated, mutating `expandedAttrs` directly can have side-effects or fail serialization.
**Action:** Use a `WeakMap` keyed by `p.expandedAttrs` to cache a `Set` of canonicalized skills, combined with a `Map` cache for canonical skill names. This yields an O(1) `Set.has` check on subsequent lookups without mutating attribute objects or interfering with garbage collection.
