## 2026-10-13 - O(1) Skill Lookups in Match Simulation Hot Loops
**Learning:** `hasSkill(p, skillName)` is called thousands of times per match simulation (in passing, shooting, defending, fatigue, and tactical decision routines). In its original form, every call performed string normalization, regex replaces, alias table lookups, and an O(N) array scan over `p.expandedAttrs.skills`. Caching canonicalized skill keys in a `Map` (`_canonSkillCache`) and lazy-building a canonical `Set` (`_canonSkills`) on `p.expandedAttrs` converted O(N) array scans with string processing into O(1) Set lookups, yielding a 55x speedup for skill checks in hot loops (from 2,504ms down to 45ms per 1M checks).
**Action:** Always lazy-cache canonicalized string collection sets on entity objects when performing frequent membership checks in simulation hot loops.
