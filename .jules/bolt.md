## 2026-09-29 - O(1) Team Lookups in Monolithic Single-Scope Bundles
**Learning:** `getTeam(id)` is called tens of thousands of times across match simulation, tournament rendering, and standings calculations. Performing `allTeams.find(t => t.id === id)` repeatedly incurs linear scan O(N) overhead per lookup across 300+ teams. Caching lookups in an internal `Map` with length/reference validation converts lookups to O(1) while remaining safe if `allTeams` is mutated or replaced.
**Action:** Always check frequently-called lookup functions (`getTeam`, `findPlayerAndTeam`) in game simulation loops and cache them in O(1) hash maps, validating array reference and length for invalidation. Remember to run `node build.js` to update `dist/app.js` whenever editing split source files under `data/`, `ui/`, `engine/`, `simulation/`, `js/`, or `ai/`.
